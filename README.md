# Pramesh Portfolio

Static site. No build step.

## Run in VS Code
1. File > Open Folder > select `Pramesh-portfolio`.
2. Install the "Live Server" extension (VS Code suggests it).
3. Right-click `index.html` > Open with Live Server.

No extension? Run in the terminal: `npm start`

## Edit
- Text: `index.html`
- Colors and layout: `css/style.css` (variables at the top)
- Links: `LINKS` block in `js/main.js`

## Deploy free
Netlify Drop, GitHub Pages or Vercel. Upload the whole folder.
