# Pramesh Portfolio

Static site. No build step.

## Run in VS Code
1. File > Open Folder > select `Pramesh-portfolio`.
2. Install the "Live Server" extension (VS Code suggests it).
3. Right-click `index.html` > Open with Live Server.

No extension? Run in the terminal: `npm start`

## Edit
- Update your name, role, contact details, social profiles and project demo URLs in the `PROFILE` block in `public/js/main.js`.
- Colors and layout: `public/css/style.css`.
- Project preview artwork: replace the conceptual previews in `public/assets/` with your own screenshots, keeping the filenames or updating the image paths in `public/index.html`.

## Deploy free
Netlify Drop, GitHub Pages or Vercel. Upload the whole folder.
